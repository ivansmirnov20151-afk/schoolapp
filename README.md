# Расписание и Звонки — веб-версия 5Б

Готовая адаптивная версия исходного Android-приложения. Главный файл — **index.html**.

## Что перенесено

- экран запуска с картинкой и вашим 32px loader;
- получение аккаунтов с GitHub Raw;
- получение домашних заданий из Raw-файлов аккаунтов;
- проверка логина/пароля по GitHub;
- гостевой вход;
- создание и проверка 4-значного PIN;
- блокировка/разблокировка;
- расписание 5Б по дням недели;
- текущий урок, перемена, обед, таймер и прогресс по системному времени;
- редактирование, удаление и добавление уроков;
- вариант «только сегодня»;
- восстановление исходного расписания;
- расписание звонков;
- оценки и средний балл;
- поддержка и режим подтверждения статуса;
- 5-минутный таймер подтверждения;
- GitHub Raw привязка и проверка публикации ДЗ;
- ИИ-репетитор с историей чата;
- AI-экран заполнения расписания по фото/демо с проверкой результата;
- настройки уведомлений, автоподсветки урока, PIN и обновлений;
- PWA manifest + service worker для установки на телефон/ноутбук при размещении на HTTPS.

## Запуск

Для максимальной совместимости запустите папку через любой локальный HTTP-сервер, например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/`.

`index.html` также можно открыть напрямую, но service worker/PWA и часть браузерных API требуют HTTPS/HTTP-контекста.

## Gemini

В исходном Android-проекте в архиве находится только `.env.example` с placeholder `MY_GEMINI_API_KEY`; реального секретного значения в переданном архиве нет. Поэтому я не подставлял выдуманный ключ.

Для встраивания ключа в готовую статическую веб-версию замените значение `BUILT_IN_GEMINI_API_KEY` в `app.js`. Дополнительно ключ можно сохранить через **Настройки → Gemini API**.

Учтите: API-ключ, встроенный в статический HTML/JS, виден посетителю сайта и его нельзя считать секретным. Для публичного сайта безопаснее использовать свой серверный proxy.
